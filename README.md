# SSwitcher

Небольшое приложение для macOS: **двойной Shift исправляет раскладку уже набранного текста (RU ↔ EN)**.

- Если есть выделение — преобразует весь выделенный текст.
- Если выделения нет — преобразует слово только когда курсор стоит сразу после его последнего символа. Например, `ghbdtn` → `привет`, `руддщ` → `hello`.
- После преобразования включает раскладку полученного текста.

Работает с левым и правым Shift: два коротких нажатия одной и той же клавиши за 300 мс. Shift с буквами, стрелками и другими модификаторами не запускает преобразование.

## Сборка и запуск

Нужны macOS 13 или новее и Xcode Command Line Tools (`xcode-select --install`). Внешних зависимостей нет.

```sh
git clone git@github.com:TonyDanzza/SSwitcher.git
cd SSwitcher
bash scripts/build-app.sh
open build/SSwitcher.app
```

Для постоянного использования перенесите `build/SSwitcher.app` в «Программы» **до выдачи разрешений** и запускайте оттуда. Сборка предназначена для архитектуры Mac, на котором выполнена команда.

1. В настройках клавиатуры macOS включите английскую и русскую раскладки.
2. Нажмите **значок SSwitcher с двумя стрелками** в строке меню. Через пункты меню выдайте два разрешения в **Системные настройки → Конфиденциальность и безопасность**:
   - **Мониторинг ввода** — распознавать двойной Shift.
   - **Универсальный доступ** — получать выделение и положение курсора, заменять текст.
3. Если приложения нет в списке разрешений, добавьте его кнопкой «+». Если macOS попросит завершить приложение, запустите его снова.
4. В TextEdit наберите `ghbdtn` и дважды коротко нажмите Shift. Затем попробуйте преобразовать выделенную фразу.

Пункт «Исправлять по двойному Shift» ставит приложение на паузу. Выбор сохраняется между запусками. Пункт «Запускать при входе в macOS» включает или отключает автозапуск через системные объекты входа. Приложение не включает его самостоятельно. Если macOS требует подтверждение, меню открывает соответствующий раздел настроек.

## Как работает первая версия

Направление определяется по преобладающим русским или латинским буквам в тексте. Если букв поровну или их нет, используется текущая раскладка. При нескольких раскладках одного языка выбирается активная, иначе первая доступная. Соответствия символов читаются из установленных раскладок macOS, включая различия «Русская» и «Русская — ПК».

Без выделения словом считается непрерывный фрагмент до пробела, табуляции или переноса строки. Знаки препинания включаются: в неверной английской раскладке `[` и `;` могут означать русские буквы. Курсор должен стоять сразу после последнего символа слова. Внутри слова, перед ним и после пробела команда ничего не меняет и не подаёт звуковой сигнал.

Для замены используется обычная команда вставки Cmd+V. Исходное содержимое буфера обмена сохраняется в памяти и восстанавливается после вставки. Если за это время пользователь скопировал что-то новое, это новое содержимое сохраняется. Выделенный фрагмент остаётся выделенным: повторный двойной Shift преобразует его обратно. Непрерывная серия быстрых нажатий объединяется в одну команду после последнего отпускания Shift и паузы 90 мс. Во время замены новые команды игнорируются и не ставятся в очередь; продолжение серии после её завершения также не запускает новую замену до паузы. Если Shift нажали снова во время восстановления выделения, приложение ждёт его отпускания до секунды и продолжает ту же замену. Если результат остался неподтверждённым, новые замены блокируются до нового пользовательского ввода или перемещения курсора; подсказка строки меню предлагает проверить текст и выделить его заново.

Слово у курсора заменяется без выделения: заранее подготавливаются буфер обмена и последовательность Backspace + Paste. Курсор не перемещается, команды Shift+стрелка и Copy не отправляются. После вставки сравнивается весь текст поля с ожидаемым результатом, чтобы отличать замену от лишней вставки. Для составных Unicode-символов и слов длиннее 256 символов нужно ручное выделение; скрытой замены через подсветку нет.

Нет постоянного опроса текста активных приложений: чтение происходит только по двойному Shift. Таблицы преобразования кэшируются для двух направлений. Accessibility других приложений читается последовательно в отдельной очереди; собственное окно проверяется на главном потоке AppKit. Текст и диапазон запрашиваются вместе. После вставки приложение проверяет результат до подтверждения или истечения срока, не повторяя удаление и Paste. В обычных полях длинное выделение восстанавливается одной командой Accessibility и проверяется через Copy. Фиксированных ожиданий 400 и 150 мс в этом пути нет.

После выдачи разрешений постоянный таймер их проверки отключается. Пока разрешения отсутствуют, приложение повторяет проверку не дольше 30 секунд; открытие меню или окна проверки и активация приложения запускают проверку снова. Диагностика обновляется только при видимом окне и останавливается при его закрытии или сворачивании.

Для Electron-приложений SSwitcher включает дерево Accessibility при необходимости и временно кэширует результат. Если редактор не предоставляет текст или положение курсора, применяется чтение уже выделенного текста через Cmd+C. В этом режиме символы нужно выделить вручную; поиск слова под курсором недоступен. В Figma нужно войти в редактирование текста: поставить курсор строго в конец слова или вручную выделить символы. Объекты и слои без редактирования текста не преобразуются. Для слова используется тот же путь без выделения, что и в обычных полях macOS. Для ручного выделения используется Copy/Paste, восстановление выделения клавишами и проверка повторным копированием, поскольку Accessibility-диапазон Figma может расходиться с её фактическим выделением. Если дерево не сообщает о готовности вставки, используется ограниченное ожидание 320 мс. Доказанное выделение всего текста поля восстанавливается одной Cmd+A. Частичный фрагмент восстанавливается пакетами по 32 стрелки; следующий пакет отправляется после получения предыдущего системной очередью. Figma при этом может показывать постепенное расширение выделения. Проверка ждёт фактического результата Copy и при известном промежуточном результате может повторить только Copy до трёх раз за 500 мс. Вставка и восстановление выделения не повторяются.

В строке меню отображаются время последнего двойного Shift и результат. «Текст заменён — подтверждено редактором» означает, что приложение прочитало результат через Accessibility или подтвердило выделенный результат повторным копированием. «Вставка отправлена; проверьте текст и выделите его заново» означает, что редактор не подтвердил результат и его нужно проверить визуально.

Пункт **«Проверить работу…»** открывает тестовое поле и показывает фактические разрешения macOS, получение Shift и отправку команд вставки. Запуск с аргументом `--check` открывает это окно сразу. Диагностика показывает способ преобразования, подтверждение выделения и время паузы, AX, снимка, отправки, подтверждения и перехода. Медиана и p95 доступны после 20 подтверждённых попыток в том же редакторе и режиме; в памяти хранятся последние 64 измерения. Это время до подтверждения редактором, момент отрисовки на экране не измеряется. Кнопка «Скопировать диагностику» копирует этот отчёт без текста поля, содержимого рабочего буфера обмена и снимков.

Приложение получает текст активного поля только при двойном Shift, обрабатывает его в памяти, не сохраняет и не отправляет по сети. История набора не ведётся, сетевых запросов и аналитики нет.

## Плавная замена

На macOS 15.2 и новее пункт **«Плавная замена»** включает короткий переход на 90 мс. Для него нужно отдельное разрешение **«Запись экрана»**; запрос доступен в меню и в окне проверки. Без разрешения преобразование текста продолжает работать.

Перед заменой SSwitcher получает точные границы слова через Accessibility и делает один снимок небольшого участка через ScreenCaptureKit. Изображение временно закрывает удаление букв и исчезает после подтверждения вставки. Снимок существует только в памяти: файлов, видеопотока, записи звука и отправки по сети нет. Захват ограничен ожиданием 55 мс; при задержке выполняется обычная замена. Любой ввод, прокрутка или смена активного приложения убирает изображение и отменяет ожидающий снимок. Поздний результат захвата не может показать старый текст. Системная настройка уменьшения движения отключает эффект.

Анимация применяется только к тексту в одной строке с достоверными координатами, полностью видимому на одном экране. Для многострочного выделения и редакторов с неполным Accessibility используется обычная замена. **В проверенной версии Figma границы слова имеют нулевой размер, поэтому анимация там пока пропускается.** Это ограничение не отключает преобразование текста. Эффект не ускоряет сам редактор и может добавить время захвата и перехода.

Диагностика показывает время снимка или причину пропуска анимации.

## Ограничения MVP

- Поиск слова требует текст и положение курсора через macOS Accessibility. Для выделенного текста доступен запасной путь через Copy/Paste. Терминалы, некоторые редакторы и игры могут не поддерживаться. Совместимость с каждым приложением требует ручной проверки.
- В защищённых полях и при Secure Keyboard Entry преобразование недоступно.
- Смешанное выделение преобразуется в одном направлении; автоматического распознавания языка каждого слова нет.
- Ошибка отображается в меню **SSwitcher** и его всплывающей подсказке, сопровождается системным звуком.
- По умолчанию сборка имеет локальную ad-hoc подпись. Для постоянной подписи можно передать `SSWITCHER_SIGN_IDENTITY` с именем своего сертификата Apple Development при вызове скрипта сборки. После смены подписи macOS может потребовать повторно выдать разрешения. Notarization для распространения пока не настроена.

## Разработка и проверки

```sh
swift test
bash scripts/build-app.sh
```

`SwitcherCore` содержит распознавание жеста, выбор направления и поиск слова с UTF-16 координатами. Приложение на AppKit использует слушающий `CGEventTap`, Accessibility и `UCKeyTranslate`. GitHub Actions запускает тесты, собирает приложение и прикладывает ZIP к запуску.

Архитектура, выбранные сроки и ссылки на документацию Apple описаны в [docs/architecture.md](docs/architecture.md). Автоматические и ручные проверки разделены в [docs/validation.md](docs/validation.md).

Ручная проверка после выдачи разрешений:

- `ghbdtn` → `привет`, `руддщ` → `hello`; замена только в конце слова; начало, середина и позиция после пробела не меняют текст.
- Выделение одного символа, нескольких слов и текста с переносами строк, цифрами, emoji.
- Левый и правый Shift; Shift + буква, Shift + стрелка, Command + Shift, долгое удержание и щелчок между нажатиями.
- Пауза, повторный запуск, отказ в разрешениях и их повторная выдача.
- TextEdit, браузерные поля и используемые редакторы отдельно.


## Иконки

Иконка приложения и монохромный знак строки меню используют общий векторный исходник `Sources/SSwitcher/BrandIcon.swift`. Знак строки меню — template image, адаптируемый macOS к теме и выделению. Иконка приложения включается в сборку как `Resources/AppIcon.icns`.

Для пересоздания размеров и ICNS:

```sh
swiftc Sources/SSwitcher/BrandIcon.swift scripts/generate-icons.swift -o /tmp/sswitcher-generate-icons
/tmp/sswitcher-generate-icons Resources
iconutil -c icns Resources/AppIcon.iconset -o Resources/AppIcon.icns
```
